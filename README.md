# Bus Ticket Reservation System

A modern bus ticket reservation and management system developed with ASP.NET Core MVC.

Users can search bus trips, select seats, and reserve tickets online.  
The system also includes an admin panel for managing trips, buses, and reservations.

---

# Features

## User Features
- View available bus trips
- Search routes and schedules
- Select seats
- Book bus tickets

## Admin Features
- Admin dashboard
- Manage bus trips
- Add / update / delete routes
- Manage buses and schedules
